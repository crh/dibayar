All existing dynamic links are fixed internal paths or server-generated IDs/tokens; no current unsafe user-controlled href or `wa.me` construction was found. URL rule (binding for M3 WhatsApp links): user-controlled text placed into a URL or message link must go through `URLSearchParams` or `encodeURIComponent`, never raw string concatenation — raw concatenation lets unescaped `&`, `?`, `#`, or newline characters in user input corrupt query boundaries or inject extra parameters/lines. Href scheme allowlist: only fixed relative app paths, or known-safe `https://wa.me/`, `mailto:`, and `https:` URLs; never a raw user-supplied string, `javascript:`, or `data:` scheme.
  - PDF render review (same date): `@react-pdf/renderer` receives values as `Text` children, not as HTML, so there is no HTML-injection surface in the invoice PDF. Caveat: control-character and unusually-long-string rendering behavior inside `@react-pdf/renderer` itself was not independently verified and remains library behavior taken on faith.
