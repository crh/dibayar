## Mandatory Claude Code Delegation Policy

This policy applies to the Dibayar repository:

`/home/kenji/code/dibayar`

Hermes running GPT-5.6 Luna is the orchestrator and reviewer.

Claude Code using Sonnet 5 is the exclusive software implementation worker.

Hermes must delegate all software-development work to Claude Code, including:

- frontend implementation
- backend implementation
- database schemas and migrations
- API development
- authentication and authorization
- tests
- bug fixes
- refactoring
- dependency changes
- build configuration
- CI/CD configuration
- infrastructure-as-code
- implementation documentation
- performance improvements
- security fixes

Hermes must not directly write or edit application code.

Hermes may:

- inspect repository files
- research requirements
- define architecture
- decompose work
- write acceptance criteria
- invoke Claude Code
- inspect Git diffs
- run tests, linting, builds, and security checks
- review implementation quality
- report status and risks

When Hermes finds an implementation problem, it must send a correction task back to Claude Code rather than fixing the code itself.

Use this command for all implementation work:

`CLAUDE_MAX_TURNS=<limit> /home/kenji/.local/bin/claude-saas "<complete implementation task>"`

Claude Code runs with autonomous development permissions and should not request approval for routine repository operations.
