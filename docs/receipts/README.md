# Dibayar receipts

Receipt-style evidence is kept outside the repository root.

- Current and non-superseded receipts live directly in this directory.
- Superseded receipts live in [`archive/`](archive/).
- The current repository status audit lives in [`../status/DIBAYAR-CURRENT-TRUTH-AUDIT-2026-09-20.md`](../status/DIBAYAR-CURRENT-TRUTH-AUDIT-2026-09-20.md).
- Use [`../../STATE.md`](../../STATE.md) for the short operational status; receipts are historical evidence and should not override it.

Receipts are preserved for provenance. Moving a receipt here does not mean its claims are current; check its date and referenced commit.
